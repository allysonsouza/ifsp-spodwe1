DOM API - Criador de Personagens

Construa um criador de personagens a partir de um formulário HTML fornecido abaixo.

Os cartões de personagem devem ser criados a partir dos dados inseridos no formulário. Ele devem ser exibidos enquanto o usuário insere os dados, na área de visualização do personagem. Após o usuário clicar em criar, a visualização deve ficar em branco e o cartão de personagem deve ser adicionado à área de listagem de personagens.

Dicas

  1. Crie uma folha de estilos para a página, pode ajudar na visualização dos elementos
  2. Utilize o evento onchange para escutar por mudanças no campo nome, do formulário. Trate no callback a inserção do nome na área de visualização do personagem.
  3. Utilize o evento onchange para fazer o mesmo procedimento anterior com os demais campos.
  4. Quando o usuário submeter o formulário, utilize preventDefault() para evitar o disparo do comportamento padrão do evento de submissão.
  5. Limpe a div.visualizacao-de-personagem e crie um novo elemento e insira-o na div.lista-de-personagens
